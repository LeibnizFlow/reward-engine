# Manuscript figures

The README uses figures from the companion `swarm-reward-manuscript` project:

- `reward_engine_overview.png`: build reward, execute by reward, and update reward (manuscript Figure 2).
- `benchmark_results.png`: three-run success consistency, relative failure reduction, and per-task score gains (manuscript Figure 3).

The source PDFs are `figures/reward_engine_overview.pdf` and `figures/benchmark_results.pdf` in that project. They were rendered to PNG with Poppler at a 2400-pixel maximum dimension, preserving content and typography without requiring the SVG source fonts. Captions and research numbers follow `main.tex`.

These figures describe the research framework and historical results. Optional counterexample review is not enabled by default in this package; the offline example does not reproduce the plotted scores.

Figure rights remain with their authors. No separate public figure license has been specified; see [licenses and provenance](../LICENSES.md).
