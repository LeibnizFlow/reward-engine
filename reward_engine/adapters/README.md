# Runtime adapters

Adapters connect the shared [Outcome core](../core/outcome/README.md) to actual task environments and evidence. They collect artifacts, preserve execution receipts, and invoke independent native grading after actor execution.

- [WorkBuddy Office](workbuddy/README.md): native workspace snapshots, multi-step tasks, and verifier integration.
- [Claw-Eval native grader](claw_eval/NATIVE_GRADER_HOOK.md) and [companion interfaces](claw_eval/companion/README.md).

See [native setup](../../experiments/README.md) for dependencies and runnable entry points.
