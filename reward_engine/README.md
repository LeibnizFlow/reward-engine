# Reward Engine package

The runnable [minimal example](../docs/quickstart.md) uses the same [Outcome core](core/outcome/README.md) as the native adapters. The core constructs criteria and executable checks, guides actor revisions, compares candidates, and persists memory.

[Adapters](adapters/README.md) supply environment-specific execution, evidence collection, and grading. Native benchmark scores remain outside the learning and selection inputs.
