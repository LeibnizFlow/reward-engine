# OpenCode campaign

`campaign` prepares and runs native Claw-Eval tasks with the shared Outcome core. `continue_rounds` resumes eligible algorithm rounds. Use each module's `--help` for configuration and output arguments.

Start with the [Claw-Eval guide](../README.md). The [Outcome core](../../../reward_engine/core/outcome/README.md) defines construction, feedback, and selection; native scores are used only after execution.
